# ADR-002：九语言人工翻译与独立发布契约

status: accepted
date: 2026-07-22

## 决策

| 语言 | URL 前缀 | 说明 |
|---|---|---|
| 英语 | `/` | 默认语言和源文 |
| 法语 | `/fr/` | 独立译文 |
| 德语 | `/de/` | 独立译文 |
| 西班牙语 | `/es/` | 独立译文 |
| 简体中文 | `/zh-CN/` | 独立译文 |
| 阿拉伯语 | `/ar/` | 独立译文，支持 RTL |
| 印地语 | `/hi/` | 独立译文 |
| 日语 | `/ja/` | 独立译文 |
| 葡萄牙语 | `/pt/` | 独立译文 |

- 语言切换指向当前内容的对应译文，不统一返回首页。
- 其他八种语言在 `wp-admin` 中分别保存、编辑、审核和发布。
- 机器翻译不直接发布；正式译文以人工内容为准。
- 未审核或未发布译文不生成公开页面，不出现在语言切换、Sitemap 或 hreflang 中。
- 已发布语言版本具有独立 slug、Meta Title、Meta Description、OG 图、canonical 和发布状态。

## 待后续任务决定

- WordPress 中译文关联的插件/数据模型。
- 无对应译文时语言切换器隐藏、禁用或提示的具体 UI。
- `x-default` 最终指向和 locale negotiation 策略。
