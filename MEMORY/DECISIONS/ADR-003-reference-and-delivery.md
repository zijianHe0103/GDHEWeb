# ADR-003：RapidDirect 参考边界与小批次验收

status: accepted
date: 2026-07-22

## 决策

- 参考 RapidDirect 的公开信息架构、页面类型、模块顺序、视觉节奏、响应式、交互、SEO 结构和询盘路径。
- 不复制商标、源码、未授权主题、图片/视频、字体或原文；全部替换为 GDHE 的品牌和内容。
- 页面和组件先建可复用模板，不为同类页面复制整页代码。
- 首页每次只开发 1～3 个模块；每批本地运行后在 1440、1024、768、390 px 截图、比较并修正。
- 差异分为严重、明显和细节；用户确认前优先解决严重和明显差异。
- 基础框架、首页批次、页面模板、多语言/SEO 和最终质量验收分阶段进行，每阶段等待用户确认。

## 影响

- `docs/reference-site-analysis.md` 作为研究证据，实施时仍需用当前参考站截图复核可能已变化的布局。
- 小批次确认门不能被自动化、agent dispatch 或构建成功绕过。
