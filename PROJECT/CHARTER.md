# 项目章程

schema_version: DPG-LANES-1.0.0

## 目标

- 为 GDHE 搭建面向海外客户的多语言 B2B 企业官网。
- 独立前端参考 RapidDirect 的信息架构、视觉节奏、响应式行为、页面组件和询盘转化路径。
- WordPress 仅作为 Headless CMS 和内容 API 来源，`wp-admin` 是最终内容管理后台。
- 使服务、行业、材料、表面处理、案例、文章、SEO 和译文可持续维护，并为后续扩展保持稳定的数据结构。

## 非目标

- 不开发第二套独立内容后台，不用 Elementor 或 WordPress 主题承担公开站前端。
- 当前不开发订单、自动报价、CRM、生产管理、独立账号系统或复杂文件处理后台。
- 不复制 RapidDirect 的商标、源代码、未授权主题、图片/视频、字体或原文文案。
- 不将机器翻译直接作为已审核的公开译文。
- 未经单独确认不部署到生产环境。

## 范围

- 公开站：全局壳层、首页、服务、行业、材料、表面处理、关于、案例、博客、联系和询盘路径。
- CMS：WordPress 内容模型、字段、发布状态、媒体、SEO 数据、语言关联和受控 API。
- 语言：英语为默认源文，法语、德语、西班牙语、简体中文、阿拉伯语、印地语、日语和葡萄牙语独立维护。
- 质量：SEO、可访问性、RTL、性能、安全、跨浏览器和 1440/1024/768/390 px 视口验收。

## 成功标准

- `wp-admin` 可管理业务内容、媒体、菜单/转化配置、SEO 字段、译文关联和独立发布状态。
- 语言切换进入当前页面的对应译文；未发布译文不生成公开 URL 或 hreflang。
- 页面模板和公共组件可复用，数据结构可稳定对接 WordPress。
- 每批 1～3 个模块完成本地启动、四视口截图、差异分级、修正和用户确认。
- 每个交付阶段有可重复的构建、测试、验证、审查和回滚证据。
