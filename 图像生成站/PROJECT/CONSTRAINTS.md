# 项目约束

schema_version: DPG-LANES-1.0.0

## 硬约束

- 不覆盖 managed block 之外的用户文件。
- 不复制已有权威文档。
- 不把 Codex 原生 memory 当作项目规则、任务状态或关键决策的唯一来源。

## 项目特定约束

- 客户照片由应用在浏览器本地处理；应用不得将照片、像素、Canvas、Blob URL 或 Base64 发送给服务器、日志、遥测或第三方。
- 不将客户照片或 SceneState 写入 WordPress、对象存储、数据库、`localStorage`、`IndexedDB` 或 Service Worker 缓存。
- 不引入图片大模型、训练、AI 渲染服务、生成队列、额度或计费。
- 不建设项目中心、历史记录、云分享、经销商 Logo 或白标。
- 第一版以桌面网页和静态效果图为限。
- 窗帘是非销售静态示意模板，不用于用布量、波数、走珠、BOM 或施工计算。
- 轨道和电机使用经过验证的真实尺寸；用户不能自由改变其厚度、纵横比和锚点。
- 尺寸参考线只建立已校准展示比例，不构成自动测量或施工精度。
- 嵌入式电动场景必须显示电机且不可隐藏。
- 正式输出固定包含 GDHE Logo、官网和免责声明。
- 访问模式只有 `approval_required`、`public`、`disabled` 三种首版状态。
- 未经 GDHE 权威资料或业务责任人确认的产品型号、尺寸、兼容关系和视觉资产不得进入正式目录。
- 缺少正确产品资产时必须禁用组合，不得使用相似产品静默兜底。
- 视觉资产优先同源提供；任何跨域资产必须经过 origin-clean 导出验证。
- 对上级 `frontend/**`、`cms/**`、产品 Schema、WordPress 数据或 Git 历史的修改，必须由后续独立任务授权。
