# 项目上下文

schema_version: DPG-LANES-1.0.0

## 背景

GDHE 独立站计划增加一个面向经销商的窗帘轨道场景展示页面。经销商使用客户提供的窗户实景照片，手动标定窗户、窗帘覆盖区域、轨道安装线和一段已知真实尺寸，然后选择 GDHE 轨道、电机、安装环境和静态窗帘示意模板。

项目早期参考了 Graber 等窗饰可视化工具的用户修正、产品放置和场景预览工作流。参考产品只提供竞争流程证据，不能代替 GDHE 真实产品数据，也不授权复制其源码、资产、文案或品牌。

需求已经收敛为确定性本地图像合成，不采用图片大模型。窗帘只辅助表达轨道效果；轨道和电机才使用真实产品尺寸和锚点。

上级独立站当前已存在 `frontend/` Next.js 技术基础和 `cms/` WordPress `gdhe-site` 插件，但产品业务模型仍存在独立的真实产品验证门。本子项目不得建立冲突的第二套产品事实。

## 运行说明

- 项目规划主文档：`PROJECT/PROJECT_PLAN.md`。
- 当前目录主要保存本子项目治理、规划和未来子项目资料；生产实现预计需要修改上级 `frontend/**` 与 `cms/**`，必须在后续任务中单独授权。
- 客户照片和临时 SceneState 只能存在于当前浏览器页面内存；不得上传、持久化或进入日志。
- 应用不保存项目，刷新或关闭页面后无法恢复。
- 访问申请和授权元数据可以由服务端保存，但必须与客户照片严格分开。
- 第一版统一使用 GDHE 品牌，不支持经销商 Logo。
- 嵌入式电动轨道的电机必须显示。
- 所有型号、尺寸、兼容关系、锚点和视觉资产在得到 GDHE 权威资料确认前均为 `UNVERIFIED`。
- 当前上级 Git 工作树是 `DIRTY`；不要为了本子项目清理或覆盖上级修改。
