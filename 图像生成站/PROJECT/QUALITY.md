# 质量配置

schema_version: DPG-LANES-1.0.0
project_type: software

## 软件项目（software）

- 适用时运行测试、lint、类型检查和构建命令。
- 关注回归风险和依赖变化。
- 检查兼容性、临时代码和无必要托底逻辑。
- 保持文档和实际行为同步。

## 本项目专项质量门

- 网络审计证明客户照片、像素、Canvas、Blob URL 和 Base64 不外发。
- 源码和运行时证明照片及 SceneState 不写入持久化存储。
- 几何单元测试覆盖归一化坐标、参考线、轨道厚度、电机锚点和无效四边形。
- 规则测试覆盖四种安装环境与手动/电动组合，尤其是嵌入式电动电机强制显示。
- 视觉回归比较固定照片中的轨道、电机、窗帘、品牌层和导出位置。
- Catalog Schema、Asset Manifest 和兼容规则使用正负例校验。
- Chrome、Edge、Safari 桌面核心流程通过。
- 大图、EXIF、色彩空间、WASM、内存释放和导出上限必须以 PoC 证据冻结。
- 每个正式产品资产具有真实来源、版本、尺寸、视角、锚点和业务批准记录。
- 缺失资产或未验证组合 fail closed，不使用错误素材兜底。
- 每次实现任务继续遵守上级前端既有 lint、typecheck、test 和 build 门。

## 研究项目（research）

- 检查来源可靠性和引用准确性。
- 保持数据到结论可追溯。
- 区分事实、推断和假设。
- 记录反例、不确定性和计算复核。

## 内容项目（content）

- 明确目标读者和内容范围。
- 检查事实、术语和风格一致性。
- 检查结构完整性、来源和版本管理。

## 商业分析项目（business-analysis）

- 明确数据口径、假设、公式和计算。
- 说明情景边界。
- 结论不得超过证据。
- 决策风险必须可见。

## 自动化项目（automation）

- 检查幂等性、权限、日志、重试、失败恢复和回滚。
- 检查外部副作用和重复执行安全性。

## 混合项目（mixed）

组合所有适用配置。混合型项目不得只用软件测试作为唯一验收方式。
